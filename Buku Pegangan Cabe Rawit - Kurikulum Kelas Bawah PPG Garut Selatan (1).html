B. Matriks Target Capaian Pembelajaran Kelas Bawah

Matriks Target 8 Semester (PAUD s/d SD Kelas 3 • 1 Semester = 5,5 Bulan)

Mekanisme Pembelajaran Kelas Gabungan (PAUD – SD Kelas 3):
1. Materi Berjenjang Individual (Tilawati & Menulis): Disesuaikan dengan jilid dan tingkat kemampuan masing-masing peserta didik dengan target tuntas (khatam) Tilawati Jilid 1–6 serta Kitabaty Jilid 1–4 dilanjutkan menyalin surat-surat pendek di akhir SD Kelas 3 (total 8 semester / 4 tahun).
2. Materi Klasikal Gabungan (Hafalan, Keilmuan, Kefahaman, Akhlak, Adab, Kemandirian & Ibadah): Disampaikan bersama-sama dan diulang bertahap sesuai jenjang kelompok tingkat.

Distribusi & Instalasi HP

Cara Install ke HP Orang Lain & Kemas ke APK

1. Instalasi Langsung di HP Android (Chrome / Edge / Samsung Internet)

  1. Host/unggah file HTML ini ke hosting gratis (GitHub Pages, Netlify, Vercel, atau server sekolah/PPG) agar memiliki URL https://....
  2. Kirim link tersebut via WhatsApp ke guru/orang tua/murid.
  3. Saat dibuka di HP Android, klik tombol "Install HP" di atas atau ketuk menu ⋮ (Titik Tiga) → "Instal aplikasi" / "Tambahkan ke Layar Utama".
  4. Ikon Cabe Rawit PPG akan muncul di layar utama HP dan bisa dibuka secara offline.

2. Instalasi di iPhone / iPad (Safari iOS)

  1. Buka link aplikasi di browser Safari.
  2. Ketuk tombol Share (Kotak dengan panah ke atas) di bagian bawah layar.
  3. Gulir ke bawah lalu pilih "Add to Home Screen" (Tambah ke Layar Utama) → ketuk Add.

3. Opsi Mengemas Menjadi File APK Android

Jika ingin membagikan file .apk secara langsung:

  • PWA Builder (pwabuilder.com): Masukkan URL website PWA yang sudah di-deploy, lalu klik Package For Stores → Android untuk menghasilkan proyek/APK TWA (Trusted Web Activity).
  • WebIntoApp / Capacitor / Android Studio: Bungkus folder berisi index.html, manifest.json, dan sw.js menjadi APK/AAB untuk distribusi internal PPG Garut Selatan.
